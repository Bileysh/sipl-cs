# Граматика SIPL

* `grammar/sipl.bnf` — БНФ у нотації курсу.
* `grammar/sipl.ebnf` — та сама граматика в EBNF, за нею написано парсер.
* `tests/grammar/valid` — 18 правильних програм, `tests/grammar/invalid` — 18 неправильних
  (у файлі `.expect` записано код помилки й позицію).

## Лексика

| Що | Як записується |
|---|---|
| ключові слова | `if then else while do begin end skip true false and or not` (лише малими літерами) |
| змінна | `[A-Za-z][A-Za-z0-9_]*`, крім ключових слів; великі й малі літери розрізняються |
| число | `[0-9]+` |
| присвоєння | `:=` |
| арифметика | `+ - * / %`, також `÷` |
| порівняння | `< <= > >= = <>`, також `≤ ≥ ≠ !=` |
| логіка | `not and or`, також `¬ ∧ ∨`, `! && \|\|` |
| коментарі | `// до кінця рядка` і `{ ... }` |

## Як знято неоднозначність БНФ

* Пріоритет задано рівнями правил: `expr → term → factor` і `cond → conj → literal`.
  Від найвищого до найнижчого: унарний `-`, `* / %`, `+ -`, порівняння, `not`, `and`, `or`.
* Бінарні операції ліво-асоціативні: `8 / 4 / 2 = 1`.
* `;` розділяє оператори й має найнижчий пріоритет. Тіло `if` і `while` — один оператор;
  щоб їх було кілька, потрібен `begin ... end`.
* `else` обов'язковий, як у БНФ курсу.

## Семантика

* Стан — значення змінних (цілі числа без обмеження розміру).
* Змінна без значення або ділення на нуль — результат не визначений (помилки R001, R002).
* `/` — ціле ділення з округленням униз, `%` — остача: `a = (a / b) * b + a % b`.
* `and` і `or` обчислюють обидва операнди.
* Після 100000 кроків виконання зупиняється (R003).

## Що додано до БНФ курсу

Операція `%`, унарний мінус, символи `÷ ≤ ≥ ≠ ¬ ∧ ∨` (щоб програми з посібника можна було
копіювати без змін) і коментарі.

| Код | Значення |

| E002 | неочікувана лексема |
